# Canonical contract snapshot

The conformance artifacts in this directory are a pinned, test-only snapshot
from `pancakebaker/dbap-integration-contracts` at commit
`6c89fb85d96110b881ff789470e3d7acfd5331e1`.

They are used to validate Bidding's serialized integration-event envelopes.
They do not replace the service-local contract types or move ownership of the
wire contract into this repository.
